# MatsyaAI Maharashtra — Technical Documentation Hub

Welcome to the technical documentation for **MatsyaAI Maharashtra**, a marine decision-support, oceanographic intelligence, and offline expedition navigation platform for fishermen across Maharashtra's six coastal districts (Palghar, Thane, Mumbai, Raigad, Ratnagiri, Sindhudurg).
