## 8. Temporal Prediction Design\nThe current dataset aligns Day T's average environment with Day T's apparent fishing effort. This is **SAME-DAY CORRELATION**, not future prediction. For real-world utility, users need to know where to fish *tomorrow*.\n
**Future Prediction Design:**\n- **Input Time**: Day T (e.g., 2026-09-04 12:00 UTC)\n- **Target Time**: Day T+1 (e.g., 2026-09-05 00:00 to 23:59)\n- **Features**: Use environmental forecasts for T+1 available at time T.\n- **Leakage avoidance**: Shift the GFW target column by -1 day relative to the environmental forecast observation date. This ensures the model learns to map (Forecast for T+1) -> (Actual Fishing on T+1).\n
## 9. Root Cause of Current Model Failure\nThe F1 = 0.0000 result is caused by a lethal combination of: \n1. **Open-Meteo Coastal Masking**: Coastal marine cells (where 80%+ of fishing occurs) return `null` for marine variables. Imputing these destroys the signal.\n2. **Same-Day Temporal Mismatch**: The inference pipeline uses instantaneous data while training uses daily means. \n3. **Severe Class Imbalance**: Missing API data makes it impossible for the model to distinguish the rare positive events from the sea of zeroes.\n
