# Matsya AI — Environmental Source Evaluation Report\n
## A. Existing Open-Meteo Problems\n- **Coastal Land Masking**: Open-Meteo's marine models operate at 0.5° resolution (~50km). Near-shore marine coordinates in Maharashtra are classified as land, returning arrays of `null` for all wave and current variables.\n- **API Fragility**: Frequent 502/DNS errors observed during large batch retrieval.\n
## B. Candidate Sources Evaluated\n1. **INCOIS (ERDDAP/GeoServer)**: Evaluated but rejected. Stale datasets (2010/2020) on public ERDDAP. Current operational data requires API keys, IP whitelisting, or institutional MOUs.\n2. **Copernicus Marine Service (CMEMS)**: Best-in-class resolution (1/12° ~ 8km) global ocean physics and wave models. Fully solves coastal masking. Requires free user registration and API key.\n3. **NOAA ERDDAP (CoastWatch)**: Excellent public, unauthenticated access. Offers high-resolution SST (0.05° ~ 5km) which easily resolves coastal cells. Wave models (WaveWatch III) are available but coarse (0.5°).\n

## E & F. Spatial Resolution & Maharashtra Coastal Coverage\n- **CMEMS**: 1/12° (approx 8km). **Coverage**: Excellent. Easily resolves the 20km coastal zone of Maharashtra.\n- **NOAA ERDDAP SST**: 0.05° (approx 5km). **Coverage**: Excellent for SST, poor for waves (0.5°).\n
## G. Temporal Resolution\n- Both CMEMS and NOAA provide Daily Mean aggregations, perfectly aligning with historical GFW data. CMEMS also provides Hourly forecasts.\n
## H. Current/Future Compatibility\n- **CMEMS**: Provides both Historical (Reanalysis) and Forecast (Analysis/Forecast) datasets mapped to the identical spatial grid. Perfect for the Future Prediction (T+1) architecture.\n
## I. License/Access Restrictions\n- **CMEMS**: Open and free for commercial/research use, but requires programmatic authentication (`copernicusmarine` Python package).\n- **NOAA ERDDAP**: 100% public, no auth required.\n
## J. Recommended Source & K. Rejections\n- **RECOMMENDED**: **Copernicus Marine Service (CMEMS)**. It is the only reliable source that provides high-resolution (8km) physics + wave data globally, ensuring coastal Maharashtra cells are properly modeled. NOAA is excellent but too coarse for wave data. INCOIS is too restricted/stale for automated DevOps.\n
